# Лучея — студия рисования и творчества

Готовый адаптивный сайт для демонстрации студии «Лучея» (Королёв).

## Запуск

Откройте `index.html` в браузере. Это автономная версия: HTML, CSS и JavaScript находятся в одном файле. Сборка, зависимости и сервер не нужны.

## GitHub Pages

В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch** → `main` → `/(root)` → **Save**.

После активации Pages сайт откроется по адресу: https://proninmike3-cyber.github.io/lucheya-studio/

## Реализовано

- Адаптивная главная страница, меню, галерея, контакты и карта.
- 23 тарифные позиции в 8 направлениях по возрастам и видам занятий.
- Прайс по возрастным направлениям; окно записи с одной кнопкой MAX (без анкеты и автосообщений).
- Семантическая разметка, SEO, поддержка клавиатурной навигации.

## Перед коммерческим запуском

Подтвердить у владельца актуальность услуг, цен, адреса, телефона, мессенджеров и согласовать использование логотипа и фотографий. Все изображения (логотип, фотографии студии, мероприятия) размещены в папке `assets/` репозитория. Внешними остаются только Google Fonts и встраиваемая карта Яндекса. Сайт не собирает персональные данные для записи: кнопка ведёт в MAX.

Исходная карточка: https://yandex.ru/maps/org/lucheya/181620678613/

## Расписание и события (обновлено 6 ноября 2026)

- Интерактивная недельная сетка занятий на **2026–2027 учебный год**, перенесена из предоставленного студией расписания. На телефонах — переключение по дням, на всех экранах — фильтр по возрастной группе. Карточки времени некликабельные, под расписанием одна кнопка «Подобрать занятие».
- Афиша творческих событий с примерами двух прошедших мастер-классов: карвинг по тыкве (10+, 1200 ₽) и роспись гипсовой шкатулки (8+, 1000 ₽). Указанные 25 октября события являются **архивными** и не доступны для текущей записи.
- Кнопка актуальных анонсов ведёт на https://vk.com/lucheya. Обновление новых событий **не автоматическое**: перед публикацией следующих мастер-классов нужно подтвердить даты и стоимость у студии.

## Локальные изображения

Фотографии, логотип и мастер-классы загружаются из `assets/`. В HTML нет ссылок на сторонние фотохостинги. Импорт исходных фотографий произведён с сайта korolive.ru. Резервные векторные иллюстрации уже встроены в HTML и не требуют подключения к внешним ресурсам.
