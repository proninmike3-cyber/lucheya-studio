# Лучея — студия рисования и творчества

Готовый адаптивный сайт для демонстрации студии «Лучея» (Королёв).

## Запуск

Откройте `index.html` в браузере. Это автономная версия: HTML, CSS и JavaScript находятся в одном файле. Сборка, зависимости и сервер не нужны.

## GitHub Pages

В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch** → `main` → `/(root)` → **Save**.

После активации Pages сайт откроется по адресу: https://proninmike3-cyber.github.io/lucheya-studio/

## Реализовано

- Адаптивная главная страница, меню, галерея, контакты и карта.
- 23 тарифные позиции в 8 направлениях по возрастам и видам занятий.
- Интерактивный выбор курса и формата, кнопки записи через WhatsApp и ВКонтакте.
- Семантическая разметка, SEO, поддержка клавиатурной навигации.

## Перед коммерческим запуском

Подтвердить у владельца актуальность услуг, цен, адреса, телефона, мессенджеров и согласовать использование логотипа и фотографий. Изображения и шрифты пока подгружаются из внешних источников. Форма составляет сообщение для мессенджера, но не сохраняет персональные данные на сервере.
